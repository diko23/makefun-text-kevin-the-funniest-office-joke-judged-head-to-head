## Entry overview

A single-line workplace humor entry under the 200-character limit. It turns on taking time off and how a team's sudden productivity without unnecessary meetings invites an unexpected response from HR.

## Run it

The grader runs the entrypoint directly with Node 22 (`node /bot/main.ts`), writing the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

```sh
node main.ts
```
